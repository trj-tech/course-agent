## 第一章 Python 基础

### 1.1 变量与数据类型
Python 是动态类型语言，变量无需声明类型即可赋值。常用内置类型包括：`int`（整数）、`float`（浮点数）、`str`（字符串）、`list`（列表）、`dict`（字典）。

示例：
```python
name = "张三"
age = 20
scores = [90, 85, 88]
info = {"name": name, "age": age}
```

### 1.2 函数
函数用 `def` 定义，可以接收参数并返回结果。函数是代码复用的基本单位。

示例：
```python
def add(a, b):
    return a + b
```

## 第二章 装饰器

### 2.1 什么是装饰器
装饰器（Decorator）是一种用于在不修改原函数代码的前提下，为函数增加额外功能的语法糖。装饰器本质上是一个接收函数作为参数、并返回新函数的函数。

示例：
```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log
def hello():
    return "hello"
```

### 2.2 装饰器的用途
常见用途：日志记录、权限校验、性能计时、缓存等。Agent 项目中常用来给工具函数加日志或权限检查。

## 第三章 面向对象

### 3.1 类与对象
类（class）是对象的模板，对象是类的实例。通过 `__init__` 方法初始化实例属性。

示例：
```python
class Student:
    def __init__(self, name):
        self.name = name

    def say(self):
        return f"我是 {self.name}"
```
